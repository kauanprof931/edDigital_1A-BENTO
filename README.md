# Livros Mágicos — Biblioteca Online

Site criado a partir do esboço enviado.

Arquivos:
- index.html
- style.css
- script.js

Funcionalidades:
- Pesquisa de livros
- Filtro por categorias
- Cards de livros
- Botões de leitura
- Navegação por seções
- Layout responsivo

Abra o arquivo index.html no navegador para visualizar.
